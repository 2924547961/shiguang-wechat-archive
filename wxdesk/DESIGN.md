# 拾光桌面界面

用户已确认保留浅绿配色，优先改善清晰度和信息主次。

- 首页顺序：当前账号与打开聊天 → 归档概况 → 最近会话及工具入口。
- 每页一个主任务。首页已有归档时突出打开聊天，同步使用次级按钮。
- 标题 26px / 700，区块标题 17px / 650，正文 14px，聊天消息 15px，辅助说明通常 12–13px。
- 正文和说明使用足够深的颜色；常规文本对比度目标至少 4.5:1。
- 通过间距、字重、边框和少量底色区分层级，减少装饰卡片及大幅宣传区域。
- 会话选中状态同时使用底色和左边线，不只靠微弱色差。
- 文案直接描述功能、状态和下一步，不用宣传口号代替页面标题。
- `frontend/clarity.css` 在基础与消息样式之后加载，统一桌面层级；不改变已导出文件。

参考：[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的可读性与对比度建议；本次未全局安装第三方 skill。
