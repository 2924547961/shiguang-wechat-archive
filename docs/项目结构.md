# 拾光项目结构

项目根目录是可直接运行的工作区，没有额外的源码副本。界面资源与 Python 后端物理分开；现有业务模块保留稳定的 `wxdesk` 包名，避免破坏账号、导出和自动回复的调用路径。

| 位置 | 职责 |
|---|---|
| `main.py` | 统一源码入口；`wxdump_gui.py` 保留旧启动方式；`wxdump.py` 提供数据库命令行 |
| `wxdesk/storage_location.py` | 首次选择归档位置，保存用户级目录指针；不移动聊天数据 |
| `frontend/` | 页面、样式、脚本和图标；经本地 `/static/` 路由提供，不包含 Python 业务逻辑 |
| `wxdesk/` | 应用后端：桌面壳、本地 API、数据库归档、媒体、导出、关系镜像和自动回复 |
| `backend/articles/` | 内置公众号文章后端：请求与分页、媒体提取、格式导出、缓存扫描、应用任务适配 |
| `mywxplus/` | 微信 UIA 适配层及其随附源码 |
| `third_party/RevokeMsgPatcher/` | 防撤回上游源码和规则；来源与许可见根目录 `THIRD_PARTY_NOTICES.md` |
| `tools/` | 图标、包分析、发送流程实验等开发辅助工具；不作为应用入口 |
| `tests/` | 自动化测试和界面冒烟测试 |
| `docs/` | 使用、环境、功能、结构和项目日志 |
| `licenses/` | 第三方许可材料 |
| `dist/` | 构建后的单文件 EXE；可重新生成 |
| `.shiguang/` | 当前账号聊天归档、媒体和设置；属于运行数据 |
| `我的导出/`、`export_*/` | 用户导出或旧归档数据 |

## 主要维护路径

运行 `python main.py` 启动源码版；运行 `python -m pytest -q` 验证；需要构建时运行 `./打包单文件.ps1`。新安装首次运行会让用户选择归档目录，默认位于 Windows 用户数据目录，选择结果仅在 `%LOCALAPPDATA%\Shiguang\archive_location.json` 保存一个路径。已存在的项目内 `.shiguang` 仍会沿用。安装步骤在 [环境与依赖.md](环境与依赖.md)，现有功能在 [功能与打包说明.md](功能与打包说明.md)，迭代记录见 [项目日志.md](项目日志.md)。

调整模块时同步检查 `拾光.spec` 的 `frontend/` 资源路径、`wxdesk/common.py` 的运行数据根目录、`wxdesk/importer.py` 调用 `wxdump.py` 的路径，以及 `tests/` 中的导入。不要将 `.shiguang/`、文章会话参数或密钥 JSON 放进构建资源。
