# 拾光 2.0 · 微信本地档案

基于原有 wxdump 取钥工具增加完整 Windows 桌面界面。功能设计参考 MemoTrace，界面与数据层在项目目录中实现。

## 打开软件

### Windows 单文件版

当前打包产物是 `dist/拾光-轻量版.exe`，可直接运行，不需要在目标电脑安装 Python。它仍包含 Qt WebEngine、取钥模块与媒体转换工具；首次启动需要先解压到系统临时目录。依赖与功能清单见 [功能与打包说明.md](功能与打包说明.md)。

在本项目中运行 `dist/拾光-轻量版.exe` 会继续使用项目已有的 `.shiguang` 归档。复制 EXE 到别的目录后，归档、设置和导出默认保存在 EXE 所在目录旁；如需带走旧归档，请将项目中的 `.shiguang` 文件夹一同复制到 EXE 旁。数据库密钥和聊天数据没有打进 EXE。

重新打包：在项目根目录运行 `./打包单文件.ps1`。脚本优先使用项目 `.venv`，也支持当前 Conda 环境；所选环境需要安装 `requirements.txt` 与 PyInstaller。打包配置见根目录 `拾光.spec`。

双击 **启动拾光.vbs**。此启动器优先使用项目 `.venv`，没有时使用可用的 Python 环境，不会打开命令行窗口。

也可以运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

原来的 Tkinter 界面保存在 `wxdump_gui_legacy.py`；原有 `wxdump.py` 命令行继续可用。环境和库见 [环境与依赖.md](环境与依赖.md)，功能清单见 [功能与打包说明.md](功能与打包说明.md)。

## 使用流程

1. 在电脑上登录微信。首页读取微信进程实际打开的数据库路径，识别当前账号；多账号可在左下角切换。
2. 点击 **开始收藏聊天 / 更新我的归档**。软件验证账号归属，获取或复用本账号密钥，制作数据库一致副本，整理聊天与媒体。
3. 在 **聊天记录** 搜索会话、筛选消息类型、按日期跳转；引用可以定位原消息，合并转发可以展开。
4. 在 **导出中心** 选择会话、日期、格式与保存目录。导出会新建独立文件夹，包含 `打开归档.html` 与导出清单。
5. 在 **年度回顾** 选择年份和个人／双人范围，生成可以单独打开的 HTML 年报。

旧 TXT 归档可通过首页的“发现旧版归档”导入。软件以 `_summary.txt` 中的账号为准，不依赖可能被误命名的导出目录。

## 格式边界

- 只能导出当前电脑实际保存的数据，已删除或未下载的原文件无法凭空恢复。
- 微信版本、表结构、DAT 编码可能变化。无法恢复的媒体显示具体状态，不当成成功。
- WXGF 可转换时导出首帧图片，不能声称完整保留该格式的动画。
- 表情包支持本地可解码的图片缓存；部分微信版本使用单独的加密缓存，暂不能解码时明确标注，不会把它误记成未下载，也不自动连接 CDN 下载。
- 可在「设置 → 联网补全表情」手动启用一次补全任务：只访问消息/表情库提供的微信表情 CDN，下载并验证图片后保存在本机，后续同步会复用。任务可取消；过期链接、缺少解密参数的表情仍无法恢复。
- 微信专有小程序、视频号消息只在消息中确有普通网页链接时提供网页跳转；本软件不会模拟微信运行小程序。
- 引用原文必须存在于当前归档或导出范围内；否则显示“原消息未包含”。
- 旧 TXT 不含原始 XML、服务端消息 ID 或真实媒体，重新同步数据库才能补充这些内容。
- SQLite 导出是结构化消息归档，并非修改原微信数据库。媒体以相对路径保存在 `assets`。
- 内嵌视频能否直接播放也取决于 Qt/操作系统可用的解码器；附件本体仍可保存。
- 手机和电脑需在同一个可互访的局域网；Windows 防火墙或访客 Wi-Fi 隔离可能阻止访问。程序不自动更改防火墙。

## 本地文件

- `.shiguang/accounts/<账号摘要>/archive.sqlite`：本地可查询的明文归档。
- `.shiguang/accounts/<账号摘要>/assets/`：恢复后的媒体文件。
- `.shiguang/settings.json`：界面设置，不包含图片密钥。
- `我的导出/`：默认导出目录，可在界面更改。
- 数据库密钥清单继续采用原工具的 JSON 格式；界面和导出数据不会展示密钥。

主界面仅绑定 `127.0.0.1`，每次启动有独立的本地访问令牌。年报分享使用另一服务，只提供当前选中的一份年报。

## 自动回复、模型与主动消息

- 「自动回复」可选择当前账号的多个好友、固定回复或 AI 回复、逐人提示词、时间感知和 0–20 秒的多消息合并；图片与表情识别开关在「AI 模型」。媒体必须已恢复到本地，所选模型也必须支持视觉输入。
- 「AI 模型」可切换 DeepSeek、OpenAI、硅基流动、OpenRouter、本机 Ollama 或自定义兼容接口。各服务商分别保存地址、模型与 Windows DPAPI 加密的 API Key。「在线获取模型」会按所填地址请求 `/models`，只在点击时联网；不提供模型列表的兼容接口仍可手动填写模型 ID。
- 「自动回复」可选择自己的 GIF、PNG、JPG 图片文件夹（包括子文件夹），按设置的概率在文字回复后尝试发送一张图片。图片发送状态请以微信会话核对。
- 「主动消息」提供立即发送和一次性定时发送。定时计划持久保存，但执行时软件必须运行、当前微信账号必须登录。发送结果不明确时不会自动重试，以免重复发送。
- 聊天页点击发送后立即返回后台任务状态。微信实际发送时间受会话切换、UIA 和网络影响；不能保证一秒内完成。测试中已打开会话约 1.8 秒，切换会话仍可能更慢。


## 2.1 更新：持续归档

- 首次完成同步后，后续按数据库变化与消息编号增量更新，复用历史记录和媒体。软件开启、微信登录时通常约半秒检查一次；设置中可关闭。读取新消息存在检查间隔，不是毫秒级监听。
- 聊天中的发送者头像来自当前账号本机头像缓存。联系人列表和通讯录导出只显示数据库标记为有效好友的个人账号；群成员资料仍保留用于显示聊天署名。
- 勾选媒体导出会同时生成离线 HTML 阅读器，包含图片、WAV 语音、视频、附件以及聊天头像。不兼容视频会尝试转成 H.264/AAC MP4 并缓存。浏览或迁移时请保留完整导出文件夹；已删除、未下载或无法解码的媒体不能保证恢复。
- 年报新增文本/引用消息字数（非空白字符，含标点）、收发字数、最长连续聊天、活跃日平均和凌晨消息。生成时同时保存 1200×1960 PNG 图片，可从年报页打开。
- 朋友圈独立同步，解析本机 SNS 缓存的动态、作者、时间、图片/视频信息、点赞、评论和位置。支持文字/作者搜索，导出当前搜索结果为离线 HTML、JSON、CSV；媒体只通过内容 MD5 精确匹配，不按尺寸猜测。未缓存的动态与无法匹配的媒体会缺失。
- 不提供自动领取红包或向微信主进程注入自动交易逻辑。


### 媒体修复更新

- 表情补全会检查消息自带的原始、加密和缩略图下载地址，并复用成功缓存；按批保存结果，可取消后续跑。设置中的“浏览时自动补全表情”会仅补全当前查看的消息，也可以点击聊天顶部的“补全表情”。下载只访问微信表情 CDN。
- 微信群头像直接读取原始文件，不重绘、不调色、不裁切。未缓存的头像使用明确的群聊占位图标。
- 朋友圈自动关联仍依赖可靠标识，缓存缩略图可能与动态中的原始 MD5 不同。无法自动关联时可点击“选择本地图片”，查看未二次压缩的本机缓存，由用户确认对应图片；尺寸排序仅用于查找，不自动认定归属。确认后的图片会一并导出。此入口不代表自动匹配已全面修复。
# 防撤回文件补丁

“防撤回”页面读取随项目保存的 RevokeMsgPatcher 规则。点击预约后，保持拾光运行并退出全部微信进程；程序先备份原始 `Weixin.dll`，再匹配当前版本的防撤回特征、写入并校验。恢复也需微信退出。文件写入成功只代表补丁已安装，重新打开微信后需要实际测试对方撤回效果。

RevokeMsgPatcher 完整源码与 GPLv3 许可证位于 `third_party/RevokeMsgPatcher/`。旧的单进程内存补丁因实际撤回测试失败而停用；文件补丁会在微信下次启动时载入。
# 自动回复、AI 模型与朋友圈 UIA 操作

侧栏“自动回复”可为当前登录账号选择最多 100 位好友并设置固定文字或 AI 回复，每位好友可有独立提示词，连续消息可合并。启用时记录当前归档水位，只处理此后同步进归档的消息；同一联系人 30 秒内最多回复一次。发送状态不确定的消息会写入处理记录，不自动重发。切换微信账号后规则不会跨账号运行。

“AI 模型”页管理兼容 `/chat/completions` 的 HTTPS 接口、模型名、API Key、统一提示词、时间感知、同一好友历史上下文及视觉识别。API Key 用 Windows DPAPI 加密；图片和表情识别要求所填模型支持图像输入，仅发送本地已恢复的媒体。“媒体管理”页汇总原图、缩略图、首帧与缺失情况，并提供本机同步及表情补全设置。

聊天记录页有直接发送框。点击后立即进入发送中，后台完成一次微信 UIA 操作并回报真实结果，不因数据库回读不确定而再次发送。已打开的目标会话可跳过重新搜索；实际发送耗时仍取决于微信 UIA、切换会话和发送节奏。读取和模型请求可以在后台运行；微信个人账号的 UIA 发送及朋友圈点赞评论仍需可交互窗口，可能切换微信到前台。

朋友圈归档卡片提供手动点赞、评论。程序先在已登录微信的 UIA 树中按作者和正文定位，并核对当前控件；定位不唯一或控件不可用时拒绝操作。微信必须处于已登录、桌面解锁且可交互状态。
图片或无文字动态可用“从微信界面选择动态”，对实时 UIA 列表的作者、时间、图片数和控件内容生成指纹，执行前重新核对。朋友圈文字按数据库变化自动更新；图片从原动态地址最多四路并发恢复。

UIA 层来自本地 `mywxplus` 项目，源码位于 `mywxplus/`，许可与来源见 `licenses/mywxplus-LICENSE.txt`、`licenses/mywxplus-NOTICE.txt`。该项目的公开 `MomentService.like/comment` 尚未实现，当前操作通过其内附的 `wechatauto` UIA 控件层执行。
