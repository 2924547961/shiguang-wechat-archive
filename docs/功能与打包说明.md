# 拾光：源码、依赖与轻量版

## 源码结构

| 目录或文件 | 作用 |
|---|---|
| `main.py`、`wxdesk/desktop.py` | Windows 桌面入口与内嵌页面 |
| `wxdesk/server.py`、`frontend/` | 本机 API、界面与任务进度 |
| `backend/articles/`、`frontend/articles.js` | 内置公众号文章下载与导出 |
| `wxdesk/incremental.py`、`wxdesk/importer.py`、`wxdesk/store.py` | 当前账号归档、增量同步与查询 |
| `wxdesk/media.py`、`wxdesk/emoji.py`、`wxdesk/moments.py` | 图片、语音、视频、表情与朋友圈 |
| `wxdesk/automation.py`、`wxdesk/llm.py`、`mywxplus/` | 自动回复、模型接口、微信 UIA 操作 |
| `wxdesk/insights.py`、`frontend/mirror.js` | 关系镜像、风格提炼、成长支持规则和练习 |
| `wxdesk/exporter.py`、`wxdesk/report.py` | 聊天导出与年度回顾 |
| `wxdesk/revoke_disk.py`、`third_party/RevokeMsgPatcher/` | 防撤回补丁与上游源码、许可 |
| `wxdump.py`、`tools/` | 数据库 CLI 与开发辅助脚本 |

## 当前功能

当前登录账号识别和微信 4.x 本地数据库访问；增量聊天归档；好友、群聊、朋友圈浏览；图片、表情、语音、视频和附件恢复；HTML、CSV、TXT、Word、SQLite 导出；年度回顾；防撤回；联系人自动回复与主动消息；多模型接口；关系镜像和证据跳转；整段或日历范围分析；自己的回复风格提炼；成长支持回复规则；30 天练习与表达检查。

关系镜像的深度观察按已核对证据生成；证据不足时明确写出。风格提炼与成长规则显示后台任务阶段。聊天、报告和 API Key 不随 EXE 打包；API Key 保存在当前 Windows 用户的 DPAPI 加密文件中。

## 运行依赖

以 `requirements.txt` 为准。安装环境见 [环境与依赖.md](环境与依赖.md)。核心依赖分组如下：

| 功能 | 依赖 |
|---|---|
| 桌面内嵌界面 | PySide6 / Qt WebEngine |
| 微信取钥与数据库 | frida、sqlcipher3、psutil、zstandard |
| 图片与加密媒体 | Pillow、pycryptodome |
| 语音与视频 | pysilk-mod、imageio-ffmpeg |
| 导出、词频和分享 | python-docx、jieba、qrcode |
| Windows UIA 与朋友圈兼容路径 | uiautomation、pywin32、pyperclip、pyautogui、opencv-python、winsdk |

PyInstaller 只把程序实际引用的模块和必要的包内二进制资产收进单文件版；排除了测试框架、数据科学框架和未使用的 Qt 模块。Qt WebEngine、SQLCipher 和媒体编解码组件仍是单 EXE 体积的主要来源。若删除这些组件，对应功能将不能使用。

## 源码测试与打包

```powershell
python -m pytest -q
node --check frontend\app.js
node --check frontend\mirror.js
node --check frontend\articles.js
.\打包单文件.ps1
```

产物：`dist/拾光-轻量版.exe`。第一次运行单文件 EXE 时，PyInstaller 会先解压运行文件。请在其他 Windows 电脑上以无聊天数据的独立目录启动，验证界面、取钥和媒体依赖；不要把项目的 `.shiguang`、导出目录或密钥文件夹一起分享。
