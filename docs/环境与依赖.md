# 开发环境与依赖

## 运行环境

- Windows 10/11 x64；本地安装并登录微信 4.x。数据库取钥和 UIA 功能依赖实际登录的微信进程。
- Python 3.12 x64。当前开发机验证版本：Python 3.12.12。建议使用独立虚拟环境。
- 首次运行可选择拾光自己的聊天归档目录；默认建议 `%LOCALAPPDATA%\Shiguang\Archive`。`--state <已有目录>` 可临时覆盖选择，设置页保存的新路径在下次启动生效；旧数据不会自动移动。
- `requirements.txt` 是源码运行依赖清单；`PyInstaller` 仅在构建单文件 EXE 时需要；`pytest` 仅在运行测试时需要。
- 当前开发机的 SQLCipher Python 包为 `sqlcipher3==0.6.2`，原先写在依赖清单中的 `sqlcipher3-binary` 与实际安装包名不一致，现已统一。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

开发验证与打包：

```powershell
.\.venv\Scripts\python.exe -m pip install pytest PyInstaller
.\.venv\Scripts\python.exe -m pytest -q
.\打包单文件.ps1
```

`打包单文件.ps1` 依次选择项目 `.venv`、当前 Conda 环境、本机兼容环境或 PATH 中的 Python。换电脑构建时先在该环境安装 `requirements.txt` 和 PyInstaller。运行现成 EXE 不需安装 Python。

## 依赖与用途

| 用途 | Python 包 |
|---|---|
| 桌面窗口和内嵌页面 | PySide6（含 Qt WebEngine） |
| 微信进程、数据库解密、消息解压 | frida、psutil、sqlcipher3、zstandard |
| 图片、加密媒体 | Pillow、pycryptodome |
| 语音、视频 | pysilk-mod、imageio-ffmpeg |
| Word、二维码、中文词频 | python-docx、qrcode、jieba |
| Windows 自动操作与识图 | uiautomation、pywin32、pyperclip、pyautogui、opencv-python、winsdk |
| 公众号文章内置下载 | requests、beautifulsoup4、python-docx、reportlab |

所有应用模块位于当前项目目录：`frontend/` 是网页界面，`wxdesk/` 是主应用后端，`backend/articles/` 是文章下载后端，`mywxplus/` 是微信 UIA 适配层，`wxdump.py` 是数据库命令行，`third_party/RevokeMsgPatcher/` 保留上游防撤回源码与许可，`tools/` 放开发辅助脚本。`main.py` 是统一入口。运行数据保存在 `.shiguang/`，不会进入构建产物。文章历史消息的临时会话参数只留在本次进程内存中。
