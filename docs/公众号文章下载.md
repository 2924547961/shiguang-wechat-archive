# 公众号文章下载

## 从界面使用

运行 `python main.py`，在左侧打开“公众号文章”。选择以下来源之一：

| 模式 | 输入 | 说明 |
|---|---|---|
| 单篇文章 | 一条 `https://mp.weixin.qq.com/s/...` 链接 | 无需公众号历史会话参数 |
| 批量链接 | 每行一条文章链接 | 去重后逐篇下载，可选择每批链接数 |
| 历史消息 | 公众号文章或主页链接，以及当前有效会话参数 | 可设置关键词、日期和最多页数；微信接口可能要求重新验证 |
| 公众号合集 | `https://mp.weixin.qq.com/mp/appmsgalbum?...` 链接 | 读取合集分页，实际可用性取决于微信返回 |

可同时勾选 HTML、Markdown、TXT、MHTML、DOCX、PDF、JSON。HTML 正文图片下载到同目录的 `images/`，离线打开仍能显示；媒体和评论仅在页面提供可访问资源时保存。下载结果和文章清单 CSV 放到选定的本地输出目录。页面右侧和任务中心会显示阶段进度；“停止任务”会在当前请求结束后生效。

历史消息模式的 `uin`、`key`、`pass_ticket` 及可选参数可以手动填写，也可以扫描自己选择的微信缓存目录。参数只保存在当前进程内存，不写入设置、任务库或日志。关闭程序即失效。不要把含会话参数的链接或运行数据分享给别人。**历史消息接口没有稳定公开保证**；单篇和批量链接可独立使用。

“兼容现有本地文章工具”折叠区保留原本的 127.0.0.1:4545 MCP 入口。内置下载不需要启动该服务。

## 代码路径

| 层 | 位置 | 职责 |
|---|---|---|
| 前端 | `frontend/articles.js`、`frontend/articles.css` | 模式、选项、进度和结果展示 |
| 本地 API | `wxdesk/server.py` | 授权后的请求路由，连接任务运行层 |
| 应用适配 | `backend/articles/service.py` | 参数验证、账号绑定、内存会话、任务与进度 |
| 下载核心 | `backend/articles/downloader.py` | 请求、分页、单篇与批量流程 |
| 内容处理 | `backend/articles/enrich.py`、`exporters.py` | 媒体、评论、格式导出 |
| 缓存扫描 | `backend/articles/cache_keys.py` | 仅扫描用户手动选择的目录 |

源码入口 `main.py`；依赖见根目录 `requirements.txt`，环境安装见 [环境与依赖.md](环境与依赖.md)。离线验证运行 `python -m pytest tests/test_articles_builtin.py -q`。
