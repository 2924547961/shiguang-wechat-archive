# AI 任务运行层与新功能

## 已接入

- `wxdesk/harness.py`：账号隔离的持久任务、阶段进度、事件日志、按任务类型限制的工具调用、检查点、取消、故障后继续。程序重启时，未完成的任务标记为可继续。任务中心可查看近期任务。外部发送和启动动作仅记录事件，不保存返回内容，也不会自动重放。
- `wxdesk/personal.py`：按日期范围读取某位好友的全部已归档文字；每条长消息也会分段覆盖。分段结果按内容哈希复用，归并成带原始消息编号的聊天记忆。记忆默认不用于自动回复，需在该好友页面启用。
- 表达练习：基于已保存的聊天记忆或关系镜像出模拟题，用户作答后逐句点评并继续下一轮；练习会话保存在当前账号目录下。
- 关系镜像和风格提炼：长任务已接入同一运行层，模型请求可复用已完成的检查点。分析仍由用户点击触发。
- 公众号文章：`backend/articles/` 是内置下载核心，`wxdesk/articles.py` 提供应用接口。单篇、批量链接、历史消息和合集下载可直接在文章页使用；原有本地 MCP 调用保留为兼容入口。
- 微信多开：使用当前微信版本匹配的“多开”规则，与防撤回规则串行写入同一 DLL。用户在页面预约，所有微信进程退出后写入；重启微信后可从页面打开新实例。各账号归档独立。
- 原生语音：在聊天记录页选择好友并点击“原生语音”。必须先在微信中打开同一好友会话。程序核对账号、进程和会话后，用电脑麦克风按住右 Alt 录制指定时长并松开发送；不移动鼠标，录音期间会暂时切换键盘焦点。已在 4.1.15.13 的文件传输助手实测新增原生语音气泡。

## 运行与验证边界

- 任务库和聊天记忆保存在软件本地数据目录。模型密钥仍使用原有的账号范围秘密存储，不写进任务库。
- 恢复只自动重跑只读模型任务。外部公众号下载和启动微信可能已经发生，故不自动重试，以免重复执行。
- 微信 4.1.15.13 安装文件上的多开与防撤回特征均已只读匹配；多开的真实登录流程需要在补丁应用并重启微信后验证。
- 原生语音依赖微信当前打开的会话和电脑麦克风；目前没有验证后台、无焦点录制，因此它会在录音期间切换键盘焦点。未在真实好友会话中执行发送测试。
- 这是针对聊天档案业务实现的任务运行层；没有把 Codex CLI / app-server 本身嵌入程序。Codex 的完整代码执行代理、沙箱、审批、子代理和开放式工具循环不在这些聊天功能中。软件仍使用用户在“AI 模型”页配置的接口。
